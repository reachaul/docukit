# DocuKit — Project Status

**Release target:** v1.0.0 · **Year:** 2026 · **Developer:** by reachaul

## Implemented in this build
- Separate File Converter and PDF Toolkit navigation.
- File Converter format selection with supported target formats filtered by source.
- Drag-and-drop and Browse Files in File Converter.
- Selected-file list with file sizes, remove-selected and clear-all actions.
- PDF to JPG/PNG and image to PDF.
- JPG/PNG/WEBP image conversion to JPG/PNG.
- Optional MarkItDown conversions to Markdown.
- PDF Toolkit: merge, split, extract, remove, rotate, reorder and compress.
- Rebranded application UI with bundled Poppins and DM Sans fonts.

## Not yet implemented
- PDF to Word / Excel / PowerPoint.
- Office documents to PDF.
- Advanced OCR interface and preprocessing.
- Visual thumbnail-based PDF page organizer.
- PDF Editor tools.
- Background worker threads and detailed progress reporting.
