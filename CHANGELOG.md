# Changelog

## [1.0.0] - 2026-11-02

### Added
- Local-first Windows document toolkit branded as DocuKit.
- File conversion workflows for supported document, image, and Markdown formats.
- PDF Toolkit operations: merge, split, extract, remove, rotate, reorder, and compress.
- Bundled Poppins and DM Sans fonts with their license texts.

### Improved
- PDF image recompression and structural optimization.
- PDF operation dialogs and application navigation.

### Notes
- OCR Tools and PDF Editor are placeholders and are not active features in this release.
