# Contributing

Thanks for your interest in DocuKit.

1. Open an issue before proposing a major feature or architectural change.
2. Keep document processing local unless a future feature explicitly documents otherwise.
3. Do not commit private documents, generated output, credentials, virtual environments, or build artifacts.
4. Include reproducible steps and sample files that contain no personal or confidential data when reporting bugs.
5. Test the affected conversion or PDF operation on Windows before submitting a pull request.
